# Kitsu Tracker Extension

Paperback 0.9 tracker extension for [kitsu.app](https://kitsu.app). It syncs your
**manga reading progress (chapter number)**.

## Install

https://jenice11.github.io/paperback-kitsu/0.9/stable/
